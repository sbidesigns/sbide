# SBIDE

Static web application.

## Deployment

Clone repository and serve contents from any static hosting provider (GitHub Pages, Netlify, Vercel, etc.).

### Requirements

- Modern browser with ES6+ support
- Optional: WebGPU for enhanced features

### Setup

1. Clone repository
2. Configure hosting to serve root directory
3. Access via configured domain

## Tech Stack

- Vanilla JavaScript (ES6+)
- CSS3 with custom properties
- IndexedDB for local storage
- Service Worker for offline capability

## File Structure

```
/
├── index.html      # Entry point
├── css/            # Stylesheets
├── js/             # JavaScript modules
├── manifest.json   # PWA configuration
├── sw.js           # Service worker
└── logo.svg        # Application icon
```
